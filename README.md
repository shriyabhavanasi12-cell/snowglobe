this project is made by following the my snow-globe tutorial from the guide of Snowglobe YSWS . it generates few of the classic comfort winter movies and series on random . the website also has a snowfall effect as soon as you open and to stop the snowfall effect you must decrease your google tab size and click on the stop button in bottom left.

how it works:
1)click "Shake the Globe".
2)the snow globe shakes
3)a random movie recommendation appears
4) enjoy the snowfall in the background
5) use the "Stop Snow" button to control the snow animation
